# Instagram-бот Twinstone для Директа

Бот отвечает клиентам в Instagram Direct 24/7:
- понимает узбекский, русский и английский и отвечает на языке клиента;
- консультирует по брусчатке, граниту, каменному ковру по вашей базе знаний (`knowledge.md`);
- собирает имя, телефон, объём и отправляет заявку менеджерам в Telegram;
- если клиент просит менеджера или менеджер сам ответил из приложения Instagram — бот замолкает в этом чате на 12 часов.

## 1. Что нужно заранее
1. Instagram-аккаунт компании переведён в **профессиональный** (Business).
2. В настройках Instagram: *Настройки → Сообщения → Инструменты для подключения* → включить **«Разрешить доступ к сообщениям»**.
3. Ключ Claude API — https://console.anthropic.com
4. (Необязательно) Telegram-бот через @BotFather + ID группы менеджеров.

## 2. Приложение Meta
1. https://developers.facebook.com → **Мои приложения → Создать** → тип «Бизнес».
2. Добавьте продукт **Instagram** → «API setup with Instagram login».
3. Подключите аккаунт компании и **сгенерируйте токен** → это `IG_ACCESS_TOKEN`.
4. *Настройки приложения → Основное* → **App Secret** → это `IG_APP_SECRET`.
5. Раздел **Webhooks**:
   - Callback URL: `https://ВАШ-ДОМЕН/webhook`
   - Verify token: то же, что `IG_VERIFY_TOKEN` в `.env`
   - Подпишитесь на поле **messages**.
6. Пока приложение в режиме разработки, оно работает для аккаунтов, добавленных в роли приложения (ваш бизнес-аккаунт — подходит). Для полноценной работы переведите приложение в режим **Live** (может понадобиться проверка Meta для права `instagram_business_manage_messages`).

## 3. Запуск
```bash
cd instagram-bot
npm install
cp .env.example .env   # заполните ключи
npm start
```

Для теста на своём компьютере дайте серверу публичный адрес: `npx ngrok http 3000` — полученный https-адрес вставьте в Callback URL.

Для постоянной работы разместите на любом хостинге с Node.js 18+ (Render, Railway, VPS) и укажите его адрес в вебхуке.

## 4. Настройка ответов
Откройте `knowledge.md` и заполните цены, адреса, телефоны, условия доставки. Бот отвечает только по этим данным — то, чего там нет, он передаст менеджеру.

## Важно
- Instagram разрешает боту отвечать только в течение **24 часов** после последнего сообщения клиента — бот сам первым не пишет.
- История диалогов хранится в памяти сервера и сбрасывается при перезапуске.
